# Stilprofil Sami (formal)

Stand 13.10.2026. Quellen: Samis eigene Angaben im Chat + stil/probe-01-kommentar-kinderliteratur.md.

## Argumentationsaufbau (von Sami selbst so festgelegt, verbindlich)
- Jedes Argument in der BBB-Reihenfolge: Behauptung, Beweis, Beispiel.
  - Behauptung: die These des Absatzes in einem klaren Satz.
  - Beweis: Beleg aus belege.md (Zitat oder Paraphrase mit Harvard-Angabe und Seite).
  - Beispiel: konkreter Fall (Unternehmen, Kampagne, Ereignis), ebenfalls aus belege.md oder dem Interview.
- Mehrere Argumente nach dem Fishbone-Prinzip (Ishikawa) ordnen:
  - Kopf: das zentrale Problem bzw. die Leitfrage.
  - Hauptgräten: wenige Ursachen- oder Einflussbereiche, je ein Unterkapitel 4.x.
  - Nebengräten: Einzelargumente innerhalb eines Bereichs, jedes in BBB.
  - Am Ende eines Bereichs kurz zurück auf den Kopf (Bezug zur Leitfrage).

## Sprachmuster aus der Schreibprobe (übernehmen)
- Kapitel- bzw. Abschnittseröffnung mit Ziel-Ankündigung.
- Ursache-Folge-Ketten: "Das resultiert in", "Das bedeutet", "im Umkehrschluss", "geschweige denn".
- "Das grundlegende Problem besteht darin, dass ..."
- Fachleute namentlich einführen.

## Aufbau im Großen (aus der erweiterten Probe)
- Einstieg: Ziel ankündigen ("In diesem ... wird erläutert, weshalb ...").
- Pro-Teil: Problem, Ursache-Folge-Kette, Fachstimme, dann "Das grundlegende Problem besteht darin".
- Abschnitt mit "Das Problem ..." bzw. Lösungsrichtung (hier: Aufklärung fehlt), mit konkreten Werkbeispielen.
- Begriff klären, bevor er benutzt wird (dort: "was ist mit Stereotypen gemeint?", in der Arbeit als Aussage).
- Gegenpositionen eigener Block: "Viele Menschen behaupten, dass ...", "X behaupten auch, dass ...", "Manche sagen auch ...", mit Verweis auf Material/Quelle.
- Fazit abwägend: "Zusammenfassend ... nur teilweise zu, denn ..., dennoch sehe ich das Risiko, dass ...", dann konkreter Lösungsvorschlag. In der Arbeit ohne Ich-Form, z. B. "Zusammenfassend lässt sich die Leitfrage nur teilweise bejahen, denn ...".
- Lange Sätze mit "denn", "jedoch", "dennoch" als Hauptverbinder.

## Nicht übernehmen
- Tippfehler, Kleinschreibung, fehlende Kommas.
- Ich-Form, Anglizismen wie "worst case", rhetorische Fragen (als Aussagesatz umformen).
